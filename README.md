
# Stay With Us

Stay With Us is a simple hotel booking website developed using Django. It helps users explore hotel accommodations and view booking-related information.

## Features

- Home page with popular destinations
- Hotels page with available accommodations
- My Bookings page
- Contact Us page
- About Us page
- Reusable navigation bar and footer using Django templates
- Shared layout using template inheritance
- CSS styling for the website

## Technologies Used

- Python
- Django
- HTML
- CSS

## How to Run the Project

1. Install Python.
2. Install Django using `python -m pip install django`.
3. Open the project folder in the terminal.
4. Run `python manage.py runserver`.
5. Open `http://127.0.0.1:8000/` in a browser.
